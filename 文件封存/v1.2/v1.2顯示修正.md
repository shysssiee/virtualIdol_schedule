# v1.2 顯示修正

版本維持 v1.2。已升級 v1.2 的網站只需要更新 docs，無資料庫變更。

1. 解壓縮更新包，將 docs 內檔案更新到 GitHub 的 docs，包含新增的 hover.js。
2. 保留你原本的 config.js。
3. 等部署成功後 Ctrl+Shift+R。不要重跑 SQL。

每次開啟或重新載入網站，預設顯示所有團體與所有分類、平台。這次頁面可繼續自行篩選，下次進站重設；時區選擇仍保留。「全選」同時清除成員、活動分類、平台篩選。

電腦滑鼠移上行程，浮卡可停留、捲動並點選已登記的直播連結。移出行程卡片後延遲 350 毫秒關閉，進入浮卡會取消關閉；浮卡顯示時定時重繪不會打斷操作。離開浮卡會關閉，也可按 × 或 Esc。手機維持點行程查看詳情。

16 項測試通過，其中兩項新增測試驗證跨入浮卡取消關閉，以及焦點留在連結時不會消失。未代你更新 GitHub。
