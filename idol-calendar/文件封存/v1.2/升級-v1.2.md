# v1.1 → v1.2 更新方式

已完成 v1.2 升級：本次顯示修正只需更新 `docs`（新增 `hover.js`），保留 `config.js`，不需再執行 SQL。詳見「v1.2顯示修正.md」。

## 更新現有網站

1. 先保留目前 GitHub 網站檔案，並備份 Supabase 資料。
2. Supabase → SQL Editor → New query，貼上 **database/upgrade-v1.2.sql 全文**並執行。這份檔案用於已安裝 v1.1 的網站，可以重複執行，包含上次 v1.1 修補；不刪除帳號、行程或變更既有直播時間。
3. 將本更新包 **docs 資料夾內的檔案**上傳到 GitHub repository 的 `docs`，取代同名檔案並加入 `timezone.js`。**保留你現有的 config.js 設定**。不要多包一層資料夾。
4. 等 GitHub Pages 部署成功，按 Ctrl+Shift+R 強制重新載入。頁尾應顯示 v1.2。
5. 站主登入 →「站主管理」→「網站設定」，填入 Google 表單網址並儲存。

既有 v1.1 請只執行 upgrade-v1.2.sql，**不要重跑 schema.sql、create-owner.sql 或 upgrade-v1.1.sql**。如果仍是 v1.0，先執行 upgrade-v1.1.sql，再執行 upgrade-v1.2.sql；全新空資料庫才使用 schema.sql。

沒有額外需要安裝的前端套件，不必建置。後台使用同一網站的 `#admin` 頁面，GitHub Pages 不需要額外路由設定或伺服器。

## 使用方式

### 日曆與行程

- 卡片顯示時間、團體、分類、已填連結的平台；完整標題在電腦懸停浮卡及點擊詳情中。手機點行程查看詳情。
- 過去、未來、已取消行程都留在登記日期。只有站主刪除才移除；篩選或切换日期不改動資料。使用「跳至日期」可直接前往歷史月份。
- 跨午夜直播顯示在兩天，隔天標示「續播」；到時間只更新「直播中／已結束」，不隱藏行程。
- 登入站主或協作者後，點日期數字或當日空白區域新增；週／日檢視可點空白時段，帶入該時段。點既有行程仍開啟詳情。
- 點日期時依目前顯示時區帶入當日 20:00，再換算到表單輸入時區；不同地區可能換日，請看表單時區標示。右上角新增仍可使用。
- 只必填標題、團體、開始時間。分類、成員、結束時間、連結、說明選填，四小時上限維持。

### 時區

- 讀者預設使用裝置時區，自動顯示當地行程時間，無須付費 IP 定位服務。側欄可選其他時區或「網站預設」，選擇記在目前瀏覽器。
- 時區換算同時影響日期、月／週／日／列表、過往紀錄及詳情；真實時間相同，「直播中」同步。
- 行程表單可選台灣 UTC+8 或韓國 UTC+9，直接填公告時間。切換輸入時區會換算目前已填時間，維持同一個實際時間；若準備照韓國公告填寫，可先選韓國再輸入。
- 「現在時間」依所選輸入時區帶入；編輯行程保留上次輸入時區。原 v1.1 行程預設台灣，原本時間不變。
- 「我的追蹤清單」上方時鐘固定顯示中原標準時間 UTC+8，每秒更新，與讀者行程顯示時區分開標示。

### 站主後台

- **總覽／行程管理**：查看所有日期的行程、新增者與更新時間；搜尋標題、團體、姓名，依日期／團體／新增者篩選，修改及刪除。每頁 50 筆，「重新整理」取得最新資料。
- **團體與共用分類**：分頁管理團體、成員、活動分類、平台。成員依團體折疊。拖曳或上下移動後按「儲存順序」；未儲存離開會提醒。團體的可用分類／平台在團體「修改」內設定。
- **協作者管理**：先在 Supabase Authentication → Users 人工 Create user，再複製 UUID 到後台授權，不要填 Email。停用可恢復；移除授權保留帳號、行程與新增者紀錄，可用原 UUID 再授權。
- **網站設定**：修改網站名稱、Google 表單網址、網站預設顯示時區。表單網址留空就隱藏「問題回報」。讀者預設使用裝置時區，主動選「網站預設」時才套用站主設定。
- 協作者維持在公開日曆登入及更新自己的行程，沒有後台入口；直接輸入 `#admin` 也無法進入。權限由 Supabase RLS 保護。

## 更新後確認

1. 頁尾版本為 v1.2；重新登入站主可以開啟四個後台入口。
2. 跳到舊行程日期，行程仍可見；跨日行程隔天有續播。
3. 以韓國時間登記一筆測試，切台灣顯示少一小時，編輯仍保留韓國。
4. 點月曆日期能新增，點既有行程只顯示詳情。
5. 協作者只能新增／修改自己的行程，不能進後台或刪除行程。
6. Google 問題回報按鈕開啟你的表單；手機時鐘與後台選單正常。

本更新包已完成本機測試，但尚未替你更新正式 Supabase 或 GitHub；執行 SQL 與上傳 docs 後才生效。
