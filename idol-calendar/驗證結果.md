# 第一版驗證結果

## 通過

- JavaScript 語法檢查。
- 6 項 Node.js 測試：台灣日期邊界、直播開始／結束邊界、提前結束與兩小時上限、重疊直播分欄、相鄰直播復用位置、使用者文字跳脫。
- 在本機 PGlite PostgreSQL 相容引擎建立模擬 auth.users / auth.uid 與 anon / authenticated 角色，執行交付的 schema.sql 成功。
- 資料權限：匿名可讀取公開行程但不能新增；A 協作者可新增／修改自己的行程，B 無法修改 A 的行程；協作者無法刪除行程、建立團體、提升自己的權限或轉移行程建立者。
- 站主可以修改其他人的行程及刪除行程；停用協作者後，其原登入身分也無法新增或修改。
- 資料庫拒絕超過兩小時的結束時間。
- 瀏覽器確認月／週／列表介面、團體全選及清除、手機列表與收起篩選、過往紀錄隱藏日曆切換按鈕。
- Browser WebMCP 唯讀行程工具：有效輸入回傳 20 筆示範行程；額外參數被拒絕。
