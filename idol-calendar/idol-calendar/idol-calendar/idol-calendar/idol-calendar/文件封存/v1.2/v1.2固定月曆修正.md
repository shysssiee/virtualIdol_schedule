# v1.2 固定月曆修正
- 日期格固定高度、七欄等寬，不因行程數量變形。
- 同日兩場以上只顯示時間、團名與團體顏色。
- 每格最多兩場，更多行程點「還有 N 場」進入當日檢視。
- 電腦浮窗保留到離開卡片與浮窗；手機點擊開啟，按關閉或空白處關閉。
- 表單移除結束時間，只儲存開始時間；直播提醒開始後兩小時停止。
- 舊資料結束時間保留在資料庫但不再使用，新建或編輯會將該欄設為空值。
- 歷史行程仍永久保留，版本維持 v1.2。
